# Job Board Client

React JavaScript client for the Laravel Job Board API.

## Stack

- React 19
- Vite
- React Bootstrap with Bootstrap 5 CSS
- Lucide React icons
- Oxlint

## Run Locally

```bash
npm install
npm run dev
```
